# Projeto Equação Quadrática


Projeto-Equacao-Quadratica

Calculadora de equações do 2º grau (ax² + bx + c = 0) feita com HTML, CSS e JavaScript. O programa calcula o discriminante (delta) e exibe as raízes na página, ou informa quando a equação não possui raízes reais.

Para testar outra equação, altere os coeficientes em script.js: calcular(a, b, c).
